## DLE Marketplace

В каталоге [`dle_marketplace/`](dle_marketplace/) находится готовый плагин для DLE 20.x — витрина и личный кабинет цифровых товаров на отдельной статической странице.

Быстрая установка:

1. Соберите или используйте `dle_marketplace.zip`.
2. Загрузите архив через менеджер плагинов DLE.
3. Создайте статическую страницу и вставьте `{include file="engine/modules/dle_marketplace.php"}`.
4. Управляйте товарами, заказами и балансами пользователей в административном разделе «Маркетплейс».

Подробности и ограничения MVP описаны в [`dle_marketplace/README.md`](dle_marketplace/README.md).
