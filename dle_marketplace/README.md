# DLE Marketplace — модуль цифровых товаров

Плагин для DLE 20.x. Витрина работает внутри отдельной статической страницы, а файлы платных товаров отдаются только после успешной покупки.

## Установка

1. Упакуйте содержимое этой директории в ZIP так, чтобы `plugin.xml` лежал в корне архива.
2. В административной панели DLE откройте **Система → Управление плагинами → Загрузить плагин** и загрузите ZIP.
3. Откройте раздел **Маркетплейс → Добавить товар**, загрузите цифровой файл и опубликуйте товар.
4. Создайте отдельную статическую страницу, например `/marketplace/`, и вставьте в содержимое:

   ```text
   {include file="engine/modules/dle_marketplace.php"}
   ```

5. Убедитесь, что для покупателей настроено пополнение баланса через администратора: раздел **Маркетплейс → Балансы**.

## Возможности

- отдельная адаптивная витрина с поиском, категориями, сортировкой и карточкой товара;
- гостевая корзина в сессии;
- встроенный баланс пользователя и атомарное списание при оформлении покупки;
- раздел «Мои покупки» с подписанными ссылками на скачивание;
- закрытое хранилище `uploads/dle_marketplace/files` и потоковая выдача файлов через модуль;
- админ-раздел для товаров, заказов, статусов и балансов;
- CSRF, одноразовый nonce оформления, экранирование вывода, whitelist расширений и случайные имена файлов;
- русский и английский языковые файлы;
- без правок ядра DLE и без CDN-зависимостей.

## Оплата

В версии 1.0 реализован внутренний баланс: администратор вручную пополняет баланс пользователя, после чего покупка списывает средства атомарно. Это сознательно не привязано к конкретному платёжному агрегатору. Внешний эквайринг можно подключить отдельным обработчиком, переводя заказ в статус `paid` после подтверждения платежа.
